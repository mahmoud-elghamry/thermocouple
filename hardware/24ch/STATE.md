## How the board got here (short)

* `0031` one board, 3x AD7124-8; `0032` circuit and parts; `0033` size 170 x 145, fab, routing;
  `0034` open-sensor default and buttons; `0035` I-111 repair (caps beside pins); `0036` cost-down.
* Schematic 467 symbols, ERC 0/0, 12 pages A3/A4, generated by `gen/build.py`; board routed 2026-10-09,
  edited incrementally since (`0012` modes). Tools: `move.py`, `capnear.py`, `finish.py`, `delta.py`,
  `pincaps.py`, `fab.py` (each run makes a new `production/24ch-reva3-<time>-<sha6>/`), `guard.py` on
  every writer. Older fab sets: `production/_OLD_DO_NOT_ORDER/` - never order from them.

## Preserve for board work

* One writer: every tool that saves the board goes through `gen/guard.py`; KiCad open = refuse.
  Opening the board in KiCad and saving rewrites text fields: close with "Don't Save" after viewing.
* Analog TC traces are never ripped (`0035` D2); `delta.py` kills only a re-netted pad's old-net copper.
* Never change a baseline to make a gate pass.
